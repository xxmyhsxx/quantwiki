# Wiki 知识使用

## 任务

直接使用量化 Wiki 回答当前应用问题。定位到实际处理问题的知识正文，按请求完成解释、比较或分析，并将知识用于应用的目标与约束。只要求定位时交付最小充分的位置集。

这是 `use-quant-wiki` 的内部能力，按明确路径读取；不依赖平台递归发现，也不单独核对或升级外派版本。执行使用入口已固定的本次包快照。

## 输入

当前问题、主题、方法或待分析表述，应用已知的对象、版本、配置、目标与约束；可选范围和回答粒度。信息已明确时直接使用，未知条件保留为未知。

知识库固定为 `/Users/xiao/Documents/Projects/quantwiki`，正文位于其 `wiki/` 下；不根据应用当前目录推断 Wiki 位置。不预读整份 INDEX、SELF、READING 或 LOG；SELF 只在判断知识库职责或覆盖时按段读取。路径不可读时报告具体位置和影响，不把访问失败写成知识缺失。

## 原则

1. **正文支持结论。** 标题、搜索片段和导航用于定位，结论依据已读正文。
2. **条件随结论保留。** 区分来源报告、Wiki 整理、当前推理与应用已验证事实；不把历史模型、配置或测量直接套到当前应用。
3. **位置可核对。** 只引用实际存在且读到相关内容的文件与章节，不编造知识位置。
4. **未找到与未核实分开。** 保留检索词、覆盖范围和访问限制，不用模型记忆冒充 Wiki 内容。
5. **只读知识，反馈交入口。** 不读取 `raw/`，不修改公共知识、来源、SELF 或源 Skill，不调用未下发维护能力，也不重复写反馈日志。

## 工作步骤

1. **明确问题并选路。** 提取对象、需要的解释或判断及应用约束。已知实际文件或章节时直接进入；只有主题或问题时，按下表读取最相关的 reference。问题跨主题且已有内容不足时再补另一份，不默认加载全部导航。复用同任务已读且有效的内容。
2. **先定位文件，再定位章节。** 按 reference 提供的入口和关键词，在相关知识目录用 `rg --files` 查文件名，或用 `rg -l` 查术语/别名，仅返回候选路径。对选中的文件再用 `rg -n` 查标题与相关命中，读取该章节及必要上下文。未命中时补查中英文名、机制和相邻方法，再扩大到 `fundamentals/`、`theory/`、`methods/`、`research/`、`implementation/`；不以输出整库匹配段落或读取 INDEX 代替定位。Reference 未列出或入口失效不等于知识不存在，仍按上述方式查找。
3. **读正文和必要关联。** 先理解对象的作用及当前段落在整体中的位置，再核对机制、前提和条件；不要只截取命中的一句话。直接内容不足时沿相关链接补前置、比较或实现。正文足以支持答案和适用边界时停止扩展，不要求读完整页。按 [Wiki 链接规范](/Users/xiao/Documents/Projects/quantwiki/wiki/README.md#知识链接与页面身份) 解析：Markdown 链接以知识页目录为基准，`#` 后为标题锚点，显示文字不是文件名。只引用实际存在且读到相关内容的位置。
4. **形成所需结果。** 将已读知识与当前事实连接，给出答案、解释、比较或分析；保留版本、模型、配置及适用条件。当前推理写明前提，当前应用效果由实际记录支持。知识不足时说明检索词、范围和具体缺口；需要原文核验或实际求解时，将需求交给入口按需读取包内 [wiki-research](../wiki-research/SKILL.md)，不自行访问 raw 或启动 ingest。
5. **交付并提供反馈材料。** 交付当前结果、关键正文依据与剩余未知。将任务摘要、已读位置、结果、限制和改进依据交给统一入口；没有缺口时如实说明。入口负责本次调用唯一的反馈记录，本能力不再单独落盘。

## 输出

答案、比较或分析附实际知识位置和适用条件。用户只需要定位时，输出可点击的绝对路径链接、实际章节及该处处理的问题。说明 Wiki 支持了什么、当前推理补充了什么，以及哪些条件或结论未核实。

向统一入口提供使用反馈材料，不单独建立检索日志、覆盖矩阵或状态文件。只有正文阅读可核对时，才能声称结果来自 Wiki；不能把来源登记或代码存在当作原文核验或应用运行验证。

## 校验

- 结论能由实际读过的正文和明确前提支持，知识路径及章节可核对。
- 来源与应用条件没有混用，推理、来源报告和实际验证分别说明。
- 未找到带有检索词和范围，访问失败及未核实没有写成知识缺失。
- 查询没有预读全库导航或全部 references；读取范围由当前问题和实际解释缺口决定，未因节省上下文而省掉必要条件。
- 已给出请求所需结果，或明确具体缺口，没有用位置清单代替所需解释。
- 未读取 raw、修改公共知识或调用维护能力；反馈材料交入口，未重复写反馈。
