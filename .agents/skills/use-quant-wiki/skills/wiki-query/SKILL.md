# Wiki 查询

## 任务

读取量化 Wiki，完成当前问题所需的定位、解释、比较或分析。

## 输入

当前问题、应用条件及所需回答深度。

使用入口提供的任务快照；Wiki 位于 `/Users/xiao/Documents/Projects/quantwiki/wiki/`。路径不可读时报告访问限制，不改用应用目录。

## 原则

本能力只读知识正文，不读取 raw、修改公共内容或调用维护 Skill。原始核验和进一步求解交入口选择 [wiki-research](../wiki-research/SKILL.md)。

依据实际读过的正文形成结果，区分 Wiki 记载、当前推理和应用实测。保留版本、模型、配置等相关条件；未找到、尚未核实和不可访问分别说明。只引用实际存在且读到相关内容的位置。

## 工作步骤

### 1. 选择入口

已知页面直接进入；否则选最相关的一份 reference，跨主题且内容不足时再补另一份。复用同任务已读且有效的内容，不预读整份 INDEX、SELF、READING 或 LOG；仅判断知识库职责或覆盖时按段读 SELF。

| 问题 | 按需读取 |
| --- | --- |
| 量化方法、校准、变换、码本、精度分配 | [量化方法](references/quantization.md) |
| 模型结构、视觉输入、MoE/MLA、KV 与生成状态 | [模型与缓存](references/models-and-cache.md) |
| 权重加载、后端、调度、分页、多卡执行 | [部署系统](references/deployment.md) |
| CUDA/Triton、布局、归约、低精度乘法与流水 | [GPU 算子](references/kernels.md) |
| 误差、质量指标、性能口径、可靠性 | [误差与评测](references/evaluation.md) |

### 2. 定位文件和章节

1. 按入口和关键词，在相关目录用 `rg --files` 查文件名，或用 `rg -l` 查术语，只返回候选路径。
2. 对选中的文件用 `rg -n` 查标题和命中位置，再读相应章节及必要上下文。
3. 未命中时补查中英文名、别名、机制和相邻方法，再扩大到 `fundamentals/`、`theory/`、`methods/`、`research/`、`implementation/`。

导航未列出或入口失效不等于知识缺失。保留查找范围和限制，避免返回整库匹配结果。

### 3. 读懂后回答

先弄清对象的作用、总体工作方式和当前章节的位置，再核对机制、前提与适用条件。不要只截取命中的一句话；缺少解释时沿链接补读，足以支持答案和边界时停止，不要求读完整页。

按 [链接规范](/Users/xiao/Documents/Projects/quantwiki/wiki/README.md#知识链接与页面身份) 解析位置：相对路径以知识页目录为基准，`#` 后是章节锚点，显示文字不是文件名。

## 输出

只需定位时交付可点击的绝对路径、章节及用途；需要解释、比较或分析时给出对应答案。向入口提供任务摘要、已读位置、结果、限制和改进依据，由入口统一反馈，本能力不另写日志。

## 校验

交付前核对：正文能否支持答案，必要条件是否遗漏，结论是否超出实际读取范围。不能把来源登记或代码存在写成原文核验或应用运行成功。
