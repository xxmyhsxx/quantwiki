# 论文入库

## 1. 任务与设计目标

读懂一篇模型量化相关论文，把理解它所需的知识补入目标 Wiki。读者具备相关数学和深度学习基础，但没有读过该论文，也应能从 Wiki 理解问题、整体方法、关键机制、证据和局限。

## 2. 使用边界

默认处理单篇论文。代码或补充材料按解释需要读取，不自动开展训练、性能测试或复现。

保留用户已有修改和原始证据。提交、推送与发布遵循用户授权及目标项目约定，不能从入库请求推导出无限制的外部操作权限。

## 3. 输入设计

论文材料与目标 Wiki 入口；按需采用用户指定的关注问题、深度、读者基础和更新范围。

## 4. 原则设计

领域知识用来发现问题和解释线索；论文结论依据原始材料，Wiki 覆盖依据实际正文。执行者熟悉某个概念，不代表 Wiki 已经把它讲清楚。

本 Skill 提供阅读和整合方法，正文写作、目录、元数据、引用与维护约定由目标 Wiki 决定。写作规范在读取约定、写入和复核时落实，避免只核格式、忽略内容是否清楚且必要；不在 Skill 中另复制一套项目规范。

## 5. 工作流程设计

先理解研究对象在所属任务中的作用，再理解整体方法、查找已有解释，最后写入并复核。内部步骤再详细，也不能替代“这个东西用来解决什么问题”的解释；已有内容充分时直接复用。

主论文和 Wiki 都没有交代、需要另找来源的知识，先说明缺口和拟补材料范围，经用户确认后获取。其他已授权且范围明确的修改直接执行。重大结构选择、超范围变更或无法解释的关键冲突只暂停受影响部分。

## 6. 输出设计

交付 Wiki 中的知识补充、来源和未解决问题；只分析或无法写入时，交付拟写内容与位置，明确未更新 Wiki。过程笔记不默认另存文件。

## 8. 校验设计

从 Wiki 入口重读，暂不借原论文补全，检查读者能否理解整体方法、步骤衔接和必要前提；再回查来源，核对关键结论和条件。这样分别检查解释是否自足、证据是否可靠。
