# VLM 压缩评测框架：从任务精度到可信度

多模态模型压缩的评测常停在几个 VQA 分数上。但压缩改变的不只是答对率：它可能改变模型对同一类图像的回答分布，也可能让模型在某些社会属性上给出更偏的结果——或者只是让回答变得不可解析。LVLM-Compress-Bench 把这两类对象分开测，并把静态权重与动态 KV cache 分开处理。

本页依据 LVLM-Compress-Bench: Benchmarking the Broader Impact of Large Vision-Language Model Compression（arXiv:2503.04982，下称论文，全文含附录研读；抽取文本缺表格，已回查作者 TeX 源码核对压缩分类表、数据集与指标表、KV 压缩主表与权重加 KV 对照表）。所有数字均为作者报告，本轮未运行任何模型。相关的方法侧内容见 [视觉语言模型中的 token 与量化对象](../fundamentals/model/vision-language-model-tokens-and-quantization.md)，可靠性维度的评测见 [量化与可靠性：选择性预测评测](../theory/quantization-reliability-and-selective-prediction.md)。

## 1. 它要补的两个缺口

论文 §1 指出，已有的压缩影响研究主要针对单模态 LLM 的下游表现与可信度，而对 LVLM 缺少系统评测，具体是两个空白：没有工作在压缩与未压缩两种情形下、跨精度指标与社会性指标全面评测 LVLM 的生成；也没有工作区分**静态张量**（形状固定的权重）与**动态张量**（随生成增长的 KV cache）两类压缩的不同影响。

论文把自身限定在「plug-and-play」压缩：不做压缩后微调，也不纳入需要微调的剪枝与低秩分解，目的是观察压缩本身在没有任何补救时造成的损伤。这一点决定了它的结论适用范围——它测的是压缩的代价，不是「压缩加微调后能做到多好」。

## 2. 评的是什么：压缩分类

框架支持的压缩与配置（论文的压缩分类表）：

| 张量 | 形状 | 量化方式 | 子类型 | 位宽 | 是否需要权重更新与校准 | 硬件友好 |
|---|---|---|---|---|---|---|
| KV cache | 动态增长 | 均匀 | — | 2、4、8 bit | 不需要 | 是 |
| | | 离群值保留 | — | 同上 | 不需要 | 否 |
| | | 分组 | 逐 token、逐通道、混合（g-KC$_N$VT$_g$、g-KC$_{g1}$VT$_{g2}$、g-KT$_{g2}$VC$_{g1}$） | 同上 | 不需要 | 是 |
| 权重 | 静态 | AWQ | — | 3、4 bit | 需要 | 是 |

三点设计选择值得注意：

**离群值保留被标注为「不硬件友好」。** 该变体（记作 OR$_s$）把一定比例 $s$ 的离群值保留为 FP16、其余做均匀量化，需要稀疏与稠密两套运算支持，因此需要额外的编译器或内核配合。作者选择均匀量化而不是原始工作里的非均匀 / k-means 路线，是为了减少压缩对数据的依赖。这与 [KV cache 量化的对象与粒度](../theory/kv-cache-quantization-objects-and-granularity.md) 中「码本查表与不规则访存难进融合内核」的判断方向一致。

**混合分组沿用 KIVI 的结论并做消融。** 混合分组包含「K 逐通道、V 逐 token」（g-KCVT）与反向（g-KTVC）两种，还区分 K 的通道分组是否跨越整个 token 维度，用它们检验 [KIVI](../methods/kivi.md) 的粒度选择在 LVLM 上是否仍然成立。

**权重侧选用 AWQ。** 框架采用无需通过权重反向更新来完成量化的 AWQ 路线。避免更新权重不等于已证明保持泛化能力；量化后的任务质量仍需在独立数据与共同协议下评价，见 [模型质量评测](model-quality-evaluation.md)。

## 3. 评测对象与指标

模型为 LLaVA v1.5-7B、v1.5-13B、v1.6-7B、v1.6-13B，另有 Qwen-VL 用于检验框架的通用性；评测只作用于 LLM 部分（该部分占 LLaVA 的绝大部分存储与计算）。数据集与指标（论文的数据集表）：

| 基准 | 类别 | 考察的指标 |
|---|---|---|
| MM-Vet | VQA 与推理 | 识别、OCR、知识、语言生成、空间感知、数学 |
| TextVQA | | 视觉问答 |
| GQA | | 视觉推理、组合式问答 |
| MME | | 综合评测 |
| ScienceQA | | 科学多模态问答 |
| VQAv2 | | 视觉、语言理解与常识 |
| POPE | 可信度 | 物体幻觉 |
| HallusionBench | | 视觉错觉、语言幻觉、定量分析与诊断 |
| PAIRS | | 偏见（性别、种族） |
| SocialCounterfactuals | | 毒性、刻板印象、能力 |

四个可信度基准里有两个使用合成数据（PAIRS 与 SocialCounterfactuals），背景与视觉内容被刻意控制得相似，只沿性别、种族等属性变化，从而把差异尽量归因到属性本身。这与「只测任务精度会漏掉的东西」直接对应。

## 4. KV 压缩的结果

主表（论文的 KV 压缩对照表；列为 MM-Vet、TextVQA、GQA、MME(P)、Sci-QA、VQAv2、POPE(R)、HallusionBench）：

| 模型 | 配置 | MM-Vet | TextVQA | GQA | MME(P) | Sci-QA | VQAv2 | POPE(R) | Hallusion |
|---|---|---:|---:|---:|---:|---:|---:|---:|---:|
| LLaVA-1.5-7B | 基线（16 bit） | 31.3 | 58.19 | 61.93 | 1344.63 | 70.24 | 78.52 | 88.21 | 36.4 |
| | 4 bit 均匀 | 0.9 | 0.12 | 0.01 | 失败 | 0.8 | 0.09 | 51.75 | 4.07 |
| | 4 bit OR$_{s=2\%}$ | 33.8 | 54.65 | 60.88 | 1226.79 | 56.02 | 76.6 | 88.72 | 38.26 |
| | 4 bit g-KC$_{128}$VT$_{128}$ | 30.9 | 57.81 | 61.93 | 1333.65 | 69.54 | 78.46 | 88.35 | 37.82 |
| | 2 bit 均匀 | 2.6 | 0.1 | 0 | 失败 | 0 | 0.01 | 51.50 | 失败 |
| | 2 bit g-KC$_{N}$VT$_{128}$ | 23.6 | 39.43 | 51.8 | 955.03 | 45.48 | 69.9 | 86.90 | 26.22 |
| | 2 bit g-KC$_{128}$VT$_{128}$ | 29.8 | 52.32 | 59.06 | 1154.07 | 62.08 | 76.2 | 88.72 | 34.28 |
| LLaVA-1.6-13B | 基线 | 48.9 | 64.25 | 65.43 | 1418.46 | 75.78 | 82.8 | 88.24 | 37.91 |
| | 4 bit g-KC$_{128}$VT$_{128}$ | 50.3 | 64.02 | 65.34 | 1408.52 | 75.69 | 82.71 | 88.28 | 38.18 |
| | 2 bit g-KC$_{128}$VT$_{128}$ | 45.5 | 61.19 | 63.83 | 1323.98 | 71.26 | 81.48 | 89.24 | 39.33 |

读法与三条要点：

**均匀量化在低比特下不是「退化」而是崩坏。** 4 bit 均匀量化的 MM-Vet 只有 0.9、TextVQA 0.12，2 bit 更差。更值得注意的是 MME(P) 一栏出现「失败」：作者在表注中说明，这部分是模型输出不可理解或毫无意义，导致评测脚本无法执行，而不是分数低。这提示评测协议必须处理「输出不可解析」这一情形，否则会把崩坏误记成缺测。

**分组方案在 2 bit 才显出决定性作用。** 4 bit 下 g-KC$_{128}$VT$_{128}$ 与基线接近；2 bit 下它仍保持大部分精度（1.5-7B 的 MM-Vet 29.8 对基线 31.3），而均匀与逐通道方案已经崩坏。这里比较的是所列 2 bit KV 配置之间的差异，不能解释为“只有 2 bit 才能接近 FP16”；同表 4 bit 分组配置也接近基线。

**13B 模型对 2 bit KV 更宽容。** 1.6-13B 在 2 bit 下多项接近甚至略高于基线（POPE(R) 89.24 对 88.24、HallusionBench 39.33 对 37.91），7B 的退化则明显更大。这属于该框架下的模型规模观察，不能推广成「大模型 KV 不需要精度」。

## 5. 四条消融观察

论文在 MM-Vet 上做了分组与位宽的扫描（观察 1-4，基线 FP16 为 36.1）：

**口径提示。** 这段消融把 FP16 基线的 MM-Vet 记为 36.1，而主表中 LLaVA-1.5-7B 的基线是 31.3、1.5-13B 是 36.1；论文同时说明分组大小扫描是在 LLaVA1.5-7B 上做的，却没有交代该消融的具体模型配置。本页保留原文数值与这一不一致，不自行换算或推断消融所用模型。

1. **给 K 分配比 V 更高的位宽更有利。** 逐 token 分组下 K3V2 达到 32.8，接近基线；反过来给 V 更高精度，在两种分组下都明显更差。作者把原因归于键的精度对注意力分数更关键——这与 [KIVI](../methods/kivi.md) 的误差传播分析一致。
2. **位宽低于 4 bit 时，逐 token 分组优于逐通道分组。**
3. **「K 逐通道、V 逐 token」优于反向。** 4 bit 下差距已经存在，2 bit 下 KCVT 显著更好，与 KIVI 的粒度结论一致。
4. **分组大小的重要性取决于是否同时量化权重。** 只压缩 KV 时，分组大小对精度影响较小；权重与 KV 同时压缩时，分组大小的选择可带来约 5% 的精度差。作者把它列为后续研究问题，说明当前还没有可迁移的选取规则。

## 6. 权重与 KV 同时压缩

论文用 g-KC$_{128}$VT$_{128}$ 与 g-C$_{128}$ 两种 KV 方案叠加 AWQ 权重压缩（论文的权重加 KV 对照表）：

| 模型 | KV 方案与位宽 | 权重位宽 | MM-Vet | TextVQA | GQA | MME(P) | Sci-QA |
|---|---|---:|---:|---:|---:|---:|---:|
| LLaVA-1.5-7B（基线 31.3 / 58.19 / 61.93 / 1344.63 / 70.24） | g-KCVT，4 bit | 4 | 33.6 | 57.49 | 63.81 | 1308.25 | 69.11 |
| | g-KCVT，2 bit | 4 | 30.6 | 51.66 | 62.39 | 1205.09 | 63.26 |
| | g-C，4 bit | 4 | 29.9 | 56.7 | 63.4 | 1321.09 | 68.36 |
| | g-C，2 bit | 3 | 失败 | 0.07 | 0.53 | 失败 | 27.35 |
| LLaVA-1.5-13B（基线 36.1 / 61.25 / 63.25 / 1360.94 / 74.89） | g-KCVT，4 bit | 4 | 37.2 | 60.87 | 65.12 | 1318.55 | 74.06 |
| | g-KCVT，8 bit | 3 | 33.6 | 59.94 | 64.55 | 1373.09 | 71.7 |

两条观察：**混合分组选择在权重也被量化时依然重要**——用逐通道 KV（g-C）叠加 AWQ 时性能一致更差，2 bit 加 3 bit 权重的组合直接崩坏；**小模型的权重要比 KV 更敏感**——7B 用 3 bit 权重加 8 bit KV 明显不如 13B 的同配置，作者据此提出对较小模型应优先保证权重精度、对较大模型权重对低比特更宽容。

论文还把「量化 KV 加量化权重在某些低精度下略优于 FP16 基线」记为一个可能存在的精度甜点，并称之为三赢（性能、权重压缩、KV 压缩）。这一现象需要谨慎对待：它来自有限任务上的均值比较，作者也把它表述为「潜在」而非结论。

## 7. 可信度指标为什么不能只看分数

论文对社会性指标的解读给出了三条容易被误读的警示，价值超过具体分数本身：

- **偏见分数下降可能只是回答错了。** 在 PAIRS 上，较差的量化方案会显示性别—职业、种族—犯罪关联度显著下降，但作者指出这来自大量错误回答，而不是偏见真的减轻。评估偏见指标时必须同时检查回答有效率。
- **刻板印象分数低也可能是生成空。** 均匀量化在 SocialCounterfactuals 上给出偏低的刻板印象分数，看起来是改进；检查生成后发现原因是输出为空，而非模型回避了刻板用词。
- **分组量化的可信度指标更稳。** 在毒性与能力两项上，分组量化即使到 2 bit 也表现良好，而均匀与离群值保留方案在 4 bit 就已不理想；同时作者报告一致性略有下降，但 Yes/No 偏置、语言幻觉与视觉错觉没有明显上升。

作者自己在局限里指出，现有指标不足以完整刻画压缩模型的影响，这套基准是「详细的第一步」而非完备方案。这与 [量化误差诊断与验证](quantization-error-diagnosis.md) 的要求一致：指标要能说明它测到了什么，不能把无效输出解释成指标改善。

## 8. 适用条件与边界

- **只看 plug-and-play 压缩。** 剪枝、低秩分解与任何需要微调的方法都不在范围内，因此不能据此判断「压缩加微调」能达到的上限。
- **只压 LLM 部分。** 视觉编码器与连接器未压缩，不能把结论外推到整图量化，也不能据此估计端到端显存收益。
- **批量与测量口径受限。** 论文的评测面向生成质量与可信度，没有给出服务吞吐或端到端延迟，效率结论需另查，见 [执行路径](quantized-matmul-scaling-execution.md) 与 [SAW-INT4](../methods/saw-int4.md)。
- **分数依赖评测脚本。** 崩坏情形会出现脚本失败（表中以「-」或「失败」标注），跨配置比较时必须先确认哪些条目是有效测量。
- **模型族有限。** 主体是 LLaVA 四个变体，Qwen-VL 只用于证明框架可迁移，不足以支撑跨架构的一般结论。

## 9. 未验证

- 未运行该框架或任何模型，未复现任何精度、可信度与显存数字；本页数据全部来自论文与其附录。
- 论文未开源代码的当前状态未核对（作者称将在给定仓库开源），因此本页只描述论文中的评测设计。
- 本页未逐项核对附录中 HallusionBench 的 Yes/No 偏置、一致性与视觉错觉等细分指标，只记录作者在正文给出的定性结论。
