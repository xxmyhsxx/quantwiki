# SplitQ：模态离群通道拆分与权重激活双补偿

SplitQ 把多模态量化冲突拆成两个层次：少数模态离群通道先单独处理；剩余共享通道再分别缓解权重量化误差与激活量化误差。它结合通道拆分、可学习变换和低秩辅助分支。重要贡献是把这些误差来源落实到不同运算路径，代价则是更多分支、辅助位宽和校准自由度。

依据 arXiv:2605.19929v1（2026-05-19，预印本），24 页含附录 A.1–A.5、全部图表和案例已全文研读。截至 2026-09-15，官方仓库固定 commit `7480f129bb5150287bb65864228d6e675e5040aa` 只有 README、LICENSE 和 .gitignore，没有可审计的算法实现。以下是论文机制与条件化教学展开，未运行模型或硬件实验。

## 1. 对象与动机

主要对象为 Qwen2.5-VL 3B/7B、LLaVA-1.5 7B/13B 的语言部分，主表包括 W4A8、W4A4、W3A3 和 W3A2。附录 A.4 另外测试视觉编码器 W4A4，不表示所有模块、所有设置均已低比特化；论文没有提供 KV cache 量化路线。（§5、附录 A.4。）

图 1–2 的观察是：模态离群值集中在少量、且不完全相同的通道。强行在所有通道上共享一个变换，会让不同模态的优化需求相互妥协。[[masquant|MASQuant]] 为每种模态学习尺度并补偿共享权重差异；SplitQ 先隔离通道结构，再处理仍留在主体中的冲突。模态来源与数值统计的区别见 [[vision-language-model-tokens-and-quantization|图文 token 与量化对象]]。

本页沿用论文 $Y=XW$ 的布局，$X\in\mathbb R^{T\times d}$、$W\in\mathbb R^{d\times o}$。$T$ 是全部 token 数，$d$ 是输入通道数；代码存储方向须按 [[linear-layer-input-channel|线性层]] 转置。

## 2. MOCD：拆分的是列通道

将通道集合划分为互不相交且覆盖全部输入维度的 $C_m,C_t,C_v$。$m$ 是主体通道，$t,v$ 分别是文字和视觉统计选出的离群通道。取 $X_j=X[:,C_j]$、$W_j=W[C_j,:]$，有

$$XW=X_mW_m+X_tW_t+X_vW_v.$$

**每个 token 都有这三组通道。**上述下标不是 token 行分组；不能把视觉 token 的 $X_tW_t$ 删除，也不能把文字 token 的 $X_vW_v$ 删除。模态 mask 用于估计哪些列特殊，随后矩阵乘法仍需累加全部通道贡献。（§4.2，式 12–15，算法 1。）

### 视觉通道：用包络找突出峰值

在视觉 token 上对每列取最大绝对值，选出分数最高的 $K_v$ 列作为 $C_v$。它描述极值幅度，不直接测量任务敏感度，也容易受少数校准样本影响。

### 文字通道：用百分位序列的聚类残差

先排除已选视觉列，剩余集合记为 $C'$。对文字 token $i$ 与通道 $c$，用该 token 内的相对幅度构建百分位：

$$r_{ic}=\frac{1}{|C'|}\sum_{j\in C'}\mathbf1\{|X_{ij}|\le |X_{ic}|\}.$$

随后对每个通道的文字百分位序列聚类，计算簇内平方残差，选出残差较大的 $K_t$ 列。若簇中心为 $\mu_{ck}$、所属簇为 $k(i,c)$，可写成

$$s_t(c)=\frac1{T_t}\sum_{i\in\text{text}}(r_{ic}-\mu_{c,k(i,c)})^2.$$

这里的评分反映相对幅度模式难以被少数簇概括的程度。逐 token 整体正比例缩放不改变百分位；它也不是梯度重要度、语义重要度或原始激活方差。一个全局方差很大、却由两个紧密簇组成的通道，簇内残差仍可以很小。因此不能把该指标简称为“找最大文字激活”。论文默认聚类数 3；具体算法实现与并列值处理尚无公开代码可核对。（§4.2，式 9–11。）

剩余列组成 $C_m$。论文说明默认模态通道比例为 2%，但实际复现仍应确认两组配额的解释、取整、互斥处理与各层尺寸，不由一个比例猜出全模型配置。

### 分组后怎样保持等价

每组使用可逆变换 $P_j$：

$$X_jW_j=(X_jP_j)(P_j^{-1}W_j),\qquad
\widehat Y_j=Q_a(X_jP_j)Q_w(P_j^{-1}W_j).$$

论文基于 [[flatquant|FlatQuant]] 学习变换。通道重排后，相当于对整个输入施加分块对角变换；它能隔离组间冲突，但不允许任意跨组通道混合。可逆性、数值条件和结构约束见 [[invertible-transforms-and-kronecker-products|可逆变换与 Kronecker 基础]]。仅有恒等式不代表输入变换、分组或多次矩阵乘法没有在线成本。

## 3. ACC：主体中的权重与激活误差分别处理

MOCD 后多数通道仍共享一个变换。记

$$A=X_mP_m,\quad B=P_m^{-1}W_m,\quad \widehat A=Q_a(A),\quad D=A-\widehat A.$$

### CWS：从主体权重减去低秩成分，再用旁路补回

将 $B$ 分解为 $(B-U_sV_s)+U_sV_s$，分别量化：

$$\widehat B=Q_w(B-U_sV_s)+Q(U_s)Q(V_s),$$

$$\widehat Y_{\rm CWS}=\widehat A\widehat B.$$

减掉容易量化受损的低秩成分后，主体残差可能更容易量化；旁路在较高位宽中保留这部分。必须先减后加：直接量化完整 $B$ 再加 $U_sV_s$ 会改变浮点目标，已经不是论文方法。两个低秩因子也量化，不能把旁路当成精确的原权重恢复。（§4.3，式 16–17。）

### MAC：补激活丢掉的那部分输出

即使权重完全精确，激活量化仍留下

$$AB-\widehat AB=DB.$$

MAC 用低秩算子近似这个映射，对文字 token 增加

$$\widehat Y_{\rm MAC}=Q(D_{\rm text})Q(U_c)Q(V_c).$$

对这些文字行，完整主体输出是 $\widehat A\widehat B+Q(D)C$，其中 $C=Q(U_c)Q(V_c)$。令 $E_B=\widehat B-B$，误差严格分解为

$$\widehat Y-AB=\widehat A E_B+D(C-B)+(Q(D)-D)C.$$

三项分别是残余权重误差、补偿算子近似误差及补偿输入再量化误差。它说明 MAC 有明确的误差对象，却不能保证加入旁路后每个输入都更好。视觉行没有 MAC 时相应误差是 $\widehat A E_B-DB$。（式 18–20；误差展开是我们的教学推导。）

文字行在共享 Transformer 内也可能携带跨模态信息；文字 MAC 有效并不证明视觉信息不重要。文中的 adaptive 是校准阶段学习与输入相关残差补偿，不能直接理解为部署时继续更新参数。

### 为什么称为“受约束的低秩学习”

从原主体权重 $W_m$ 的截断 SVD $U_r\Sigma_rV_r^\mathsf T$ 出发，两种旁路按各自秩使用

$$U_*=P_m^{-1}U_r,\qquad V_*=\Sigma_rG_*V_r^\mathsf T,$$

其中 $G_*$ 是可学习对角矩阵，$*$ 分别表示 CWS 与 MAC。校准调整对角门控与变换，因子并非两块完全自由的 LoRA 参数。$P_m$ 学习会改变左侧因子，但右侧仍位于选择的奇异向量子空间中；仅调整门控不能凭空恢复子空间外的新方向。这样限制参数量和搜索空间，同时也限制适应能力。论文比较固定/学习分支，并未通过对照实验证明任意无约束低秩学习必然过拟合。（式 21，附录 A.2.2。）

## 4. 实现流程与位宽必须一起描述

算法 1 可整理成以下流程：收集带模态 mask 的校准激活 → 视觉极值选列 → 剩余文字列评分并拆分 → 为各组建立变换 → 主体初始化 CWS/MAC 低秩子空间 → 用重构目标学习变换和门控 → 固定参数，部署三组矩阵路径与文字补偿。

推理阶段还需实现通道布局、变换和量化、主体低秩运算、文字残差选择、三组结果相加。论文采用重构型 PTQ，原始模型不是重新预训练；优化器、学习率、精确 loss reduction、量化分组和所有融合细节仍不能从未公开代码中推断。

**W3A2/W3A3 主要描述主体矩阵。**论文 §5 的实现设置将模态特殊路径及辅助分支保持至少 4 bit；因此有效模型位宽还包括特殊列、CWS/MAC 因子、变换、尺度和未量化模块。MAC 需要保留/构造量化前后激活差，CWS 和 MAC 各增加低秩乘法。实际存储和运行代价见 [[quantized-matmul-scaling-execution|低比特执行与辅助分支]]。

默认 CWS/MAC 秩比例分别为 2%/3%（附录 A.2.1）。它们是论文默认选择，不是所有位宽的最优常数；主干不同尺寸对应不同实际秩，也应考虑内核对齐。

## 5. 有辨别力的实验与局限

以下数字均为作者报告。主表 1 的六任务平均与部分消融的三任务平均不同；表 2 的 LLaVA 比较也采用自己的任务集合，不能混成一条排序。

### 主体降到 3/2 bit 后保住了多少能力

表 1，Qwen2.5-VL 7B 的 FP16 六任务平均是 74.3，SplitQ W4A4 为 73.5、W3A3 为 69.5、W3A2 为 53.7。3B 对应 70.0、69.6、64.5、49.2。W3A3 的保留程度有价值，但 W3A2 仍有约 20 分绝对损失，不能描述为几乎无损。表 2 的 LLaVA 结果提供另一模型家族支持，尚不能推广到音频、多轮长上下文或所有视觉编码器。

### 三个模块为什么都要有

表 6，Qwen2.5-VL 7B W3A2 三任务平均从 FlatQuant 的 9.6，依次变为 MOCD 22.5、再加 CWS 31.4、再加 MAC 50.9。这支持在该设置下逐层解决剩余误差；不能把总提升全部归给通道拆分。W3A3 对应 59.9 → 65.3 → 66.0 → 68.0，组件收益明显随位宽改变。

表 4 同时比较随机选列与视觉极值选列。7B W3A3 三任务平均，无拆分 59.9、随机 63.5、视觉极值 64.4、MOCD（3 簇）65.3；说明单纯分组已有收益，不能将全部提升归于文字评分。3B 的 3 簇与 5 簇结果相同，也不支持 3 是普遍唯一最优。

### 为什么只对文字做 MAC，门控是否值得学

表 5，7B W3A2 不加 MAC 为 31.4，对视觉补偿 40.6，对文字补偿 50.9，两者都补偿仍为 50.9；3B 文字 46.2、两者 46.6。它支持作者在这三个任务上的成本取舍，并不确立所有任务中文字比视觉更重要。

表 10，7B W3A3 不加 CWS 为 65.8，固定分支为 64.3，可学习分支为 68.0；3B 也出现固定分支退化。低秩成分来自 SVD 并不足以保证适合量化，学习门控有实质作用。表 8–9 的秩扫描中，W3A2 某些更大秩更好，所以默认 2%/3% 仍是条件化选择。

### 校准稳定性和视觉编码器证据有多强

表 3 以 128 样本选出的通道为参照，改变至 32/64/256 样本后，报告约 89.5–95.7% 的 Jaccard 重合率。它检验的是通道集合相似性，不等价于精度不变或跨数据分布稳健。

附录表 13 对 Qwen2.5-VL 7B 的三个任务，FP16 编码器配 W4A4 LLM 平均 67.7，编码器也 W4A4 后为 67.5，完整 FP16 为 68.6。这是有限配置下的编码器兼容量化证据；没有展开足够的编码器方法和配置以支持全部复现。附录 A.5 的少量案例含成功和失败，不能据此证明稳定视觉依赖或排除语言先验。

### 速度是 W4A4 prefill 的结果

表 7、12 使用 RTX 4090、Qwen2.5-VL 7B、序列长度 2048、W4A4 prefill。batch 8：FP16 2146.01 ms/17.27 GB，MBQ 643.68/8.89，MASQuant 696.44/9.42，SplitQ 742.17/9.48。SplitQ 相对 FP16 约 2.89 倍加速，但比表内 MASQuant 慢约 6.6%、比 MBQ 慢约 15.3%。

表 12、batch 1：仅 MOCD 70.99 ms/4.85 GB，加 CWS 为 75.55/5.05，再加 MAC 为 81.78/5.42。辅助分支有可见开销；没有 W3A2/W3A3 真实内核计时或 decode 结果。论文称采用基于 Nunchaku 的定制 CUDA 实现，但当前官方仓库无法核对该路径，不能据论文式子推定真实执行性能。

## 6. Strong / weak 与相邻方法的关系

**Strong**：先找模态冲突在通道上的位置，再区分权重与激活误差；组件消融提供了这些设计在目标设置下各自有用的证据；受约束门控让低秩分支具备有限的校准适应能力。

**Weak**：通道统计与门控依赖校准集；固定子空间、比例和额外位宽限制可推广性；极低位宽仍有明显能力损失；公开算法与融合内核缺失，实际成本只获论文特定 W4A4 prefill 实验支持。

与 [[masquant|MASQuant]] 相比，SplitQ 的组变换按列分区，CWS 改写主体权重，MAC 另外补激活残差；两者不能因为都用低秩就视为同一个目标。与 [[flatquant|FlatQuant]] 相比，它增加模态分组和误差旁路，缩小了跨组混合空间并改变执行图。与 [[mbq-vlmq-comparison|模态加权重构]] 相比，它不仅调整哪些误差更重要，还改变了表示和计算路径。这些差别比跨论文最高平均分更适合支撑后续研究选择。
