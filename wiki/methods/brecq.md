# BRECQ：块级重构与二阶误差的粒度选择

逐层重构把每层的输出误差压到最小，但在位宽继续下降时反而不再有效：单层看上去接近无损，整网输出却偏得很远。BRECQ 的问题是，重构应该在哪个粒度上定义——一层、一个基本模块、一个 stage，还是整个网络。它给出的答案是把基本模块（block）作为重构单元，并把这一点建立在对二阶误差的分解上。

本页依据 BRECQ: Pushing the Limit of Post-Training Quantization by Block Reconstruction（arXiv:2102.05426，ICLR 2021，下称论文，全文研读；抽取文本缺表格，已回查作者 TeX 源码核对全部结果表）。所有数字均为作者报告，本轮未运行模型。

## 1. 对象与动机

目标是后训练量化：只有全精度权重与少量校准数据，不做端到端重训。论文指出此前方法的边界在于位宽：DFQ 在 ResNet-18 上做到 8 bit 无损（69.7% top-1），但到 4 bit 只剩 39%，而 [AdaRound](adaround.md) 用逐层重构把 4 bit 拉回可用水平，仍无法继续压到 INT2。

作者给出的原因很直接：AdaRound 的分析建立在二阶泰勒展开上，而当权重扰动变大时，它对 Hessian 的两条近似（层间独立、预激活 Hessian 为常数对角）不再成立，需要一个更准确的信号。论文的做法是保留二阶框架，但重新选择重构的粒度。

## 2. 二阶误差的两个极端

论文先给出一个可以把参数空间的二阶误差转换到网络输出的结论。对收敛到局部极小的模型，Hessian 可近似为 Gauss-Newton 矩阵

$$\mathbf H^{(\theta)}\approx\mathbf G^{(\theta)}=\mathbf J_{\vec z^{(n)}}(\theta)^{\mathsf T}\mathbf H^{(\vec z^{(n)})}\mathbf J_{\vec z^{(n)}}(\theta),$$

其中 $\vec z^{(n)}$ 是网络输出、$\mathbf J$ 是输出对参数的 Jacobian。利用 $\Delta\vec z^{(n)}\approx\mathbf J\Delta\theta$，论文证明（附录给出完整推导）

$$\arg\min_{\widehat\theta}\Delta\theta^{\mathsf T}\overline{\mathbf H}^{(\theta)}\Delta\theta\approx\arg\min_{\widehat\theta}\mathbb E\left[\Delta\vec z^{(n),\mathsf T}\mathbf H^{(\vec z^{(n)})}\Delta\vec z^{(n)}\right].$$

等号右边只依赖网络最终输出的变化，形式上与知识蒸馏一致。论文同时指出它的实用问题：蒸馏需要与常规训练相当的算力与数据，而 PTQ 只有少量校准样本。

作者进一步给出经验判断：**在 1024 张校准图上优化整个网络容易过拟合。** 当参数量远多于样本数时，训练误差下降不保证测试误差下降；而逐层重构相当于一种正则，通过匹配每层的输出分布降低泛化误差。于是两个极端各有毛病：逐层忽略层间依赖，整网则方差过大。合理的做法是取中间粒度。

## 3. 重建粒度的选择

论文按 Hessian 的结构定义四种重建单元：

| 粒度 | 对应的 Hessian 结构 | 说明 |
|---|---|---|
| 逐层 | 层对角 | 不考虑层间依赖，等价于既有逐层方法 |
| 块级 | 块对角 | 按残差瓶颈块等基本模块重构，忽略块间依赖 |
| stage 级 | 更大分块 | 同时优化一个 stage 内所有层，考虑更多依赖 |
| 整网 | 完整 Hessian | 只重构最终输出，在少样本下泛化误差大 |

在 2 bit 权重（首末层除外）上的消融（论文的重建粒度对照表，ImageNet 验证精度）：

| 模型 | 逐层 | 块级 | stage 级 | 整网 |
|---|---:|---:|---:|---:|
| ResNet-18 | 65.19 | 66.39 | 66.01 | 54.15 |
| MobileNetV2 | 52.13 | 59.67 | 54.23 | 40.76 |

块级在两个模型上都最好，整网最差，与第 2 节的判断一致。作者的机理解释是：Hessian 中主要的非对角损失集中在每个块内部，块间的部分较小，而残差连接进一步提高了块内的依赖；stage 与整网则被泛化误差压过。

论文对此保持了诚实的边界：这个分析**没有**给出最优粒度的理论解，块级是实验结论；选它的理由是它不含额外超参数，且在作者测试的所有模型与任务上适用。移动端与检测任务的实现细节（例如哪些层不属于任何块）见第 5 节。

## 4. 预激活 Hessian 的近似

块级重构仍然需要块之后的信息，即预激活 Hessian $\mathbf H^{(\vec z^{(\ell)})}$。AdaRound 假设它是常数对角（$c\cdot\mathbf I$），目标退化为输出变化的平方范数。BRECQ 改用对角 Fisher 信息矩阵：

$$\overline{\mathbf F}^{(\theta)}=\mathbb E\left[\nabla_\theta\log p_\theta(y|x)\nabla_\theta\log p_\theta(y|x)^{\mathsf T}\right],$$

其对角元素是梯度平方的期望，样本梯度平方是相应估计信号。不能用批量平均梯度再平方替代：不同样本的梯度可能相互抵消。于是优化目标成为

$$\min_{\widehat{\mathbf w}}\ \mathbb E\left[\Delta\vec z^{(\ell),\mathsf T}\mathrm{diag}\left(\left(\frac{\partial\mathcal L}{\partial \vec z^{(\ell)}_1}\right)^2,\dots\right)\Delta\vec z^{(\ell)}\right].$$

直观差别是：梯度绝对值大的输出元素在重构中被赋予更大权重，而常数对角假设一视同仁。论文引用 Lee 等的结果说明，当模型分布与真实数据分布一致时损失 Hessian 等于 FIM；并承认这个条件无法严格满足，只是在模型已收敛的前提下能做到的最好近似。这里的「最好」是相对该近似框架而言，不是对任务损失的全局保证。

## 5. 算法与实现

**权重侧用自适应舍入。** 论文直接沿用 [AdaRound](adaround.md) 的做法：权重先向下取整，再由可学习变量经 sigmoid 决定是否进位，配合退火的正则项迫使变量收敛到 0 或 1。BRECQ 的增量在于把它放在块级目标与 FIM 加权之下。

**激活侧学习步长。** 激活随输入变化，不能直接沿用为每个固定权重保存一个舍入变量的参数化；本文因此选择学习激活步长。这是该算法的选择，不代表所有激活量化方法只能调整步长。论文给出步长梯度的分情况表达（按输入与裁剪阈值的大小关系分三段），并对块内所有步长一起优化。

**实现设置（论文实现细节一节）：** 校准集为 ImageNet 中 1024 张 224×224 图像；量化前把 BN 折叠进卷积并冻结统计量；Adam 优化，权重学习率 $10^{-3}$、激活步长 $4\times10^{-5}$，每个块迭代 $2\times10^{4}$ 次、batch size 32；不实现原论文的梯度缩放。不属于任何块的层（第一个卷积、最后一个全连接，以及 MobileNetV2 的最后一个卷积）退回逐层重构。重构后把每层的敏感度与硬件性能存进查找表，2 bit 时额外保存块内敏感度。

**混合精度。** 论文用遗传算法在查找表上搜索满足时延或体积约束的位宽配置：种群 50、进化 100 代、变异概率 0.1，通常约 3 秒完成；候选位宽为 2、4、8 bit。硬件性能来自自研的精度可变加速器模拟器（周期级仿真）与移动 ARM CPU 上的低位宽 GEMM 实现，后者在 Raspberry Pi 3B 上验证。

## 6. 实验

**仅权重量化（论文主结果表，ImageNet 验证精度；下表摘录四个模型）。** 首层和末层保留 8 bit，因此表中 2/32 不是全模型每层均为 2-bit 权重；4/32、3/32 同样有该例外。主表与后文研究首末层的单独消融须区分。

| 方法 | 位宽 | ResNet-18 | ResNet-50 | MobileNetV2 | RegNet-600MF |
|---|---|---:|---:|---:|---:|
| 全精度 | 32/32 | 71.08 | 77.00 | 72.49 | 73.71 |
| 偏置校正 | 4/32 | 50.43 | 64.64 | 62.82 | 67.09 |
| OMSE | 4/32 | 67.12 | 74.67 | — | — |
| AdaRound | 4/32 | 68.71 | 75.23 | 69.78 | 71.97 |
| AdaQuant | 4/32 | 68.82 | 75.22 | 44.78 | — |
| Bit-Split | 4/32 | 69.11 | 75.58 | — | — |
| BRECQ | 4/32 | 70.70 | 76.29 | 71.66 | 73.02 |
| AdaRound | 3/32 | 68.07 | 73.42 | 64.33 | 67.71 |
| Bit-Split | 3/32 | 66.75 | 73.24 | — | — |
| BRECQ | 3/32 | 69.81 | 75.61 | 69.50 | 71.48 |
| AdaRound | 2/32 | 55.96 | 47.95 | 32.54 | 25.66 |
| BRECQ | 2/32 | 66.30 | 72.40 | 59.67 | 65.83 |

方法间的差距随位宽下降而拉大：4 bit 时 BRECQ 相对 AdaRound 约高 1 到 2 个点，3 bit 时大致持平或更高，2 bit 时 AdaRound 已接近不可用（MobileNetV2 32.54），BRECQ 仍有 59.67。这正是论文声称「首次把 PTQ 推到 INT2」的依据所在。

**权重与激活同时量化（4 bit 激活，沿用主实验首末层权重 8 bit 的设置）。**

| 方法 | 位宽 | ResNet-18 | ResNet-50 | MobileNetV2 |
|---|---|---:|---:|---:|
| 全精度 | 32/32 | 71.08 | 77.00 | 72.49 |
| ACIQ-Mix | 4/4 | 67.0 | 73.8 | — |
| ZeroQ | 4/4 | 21.71 | 2.94 | 26.24 |
| LAPQ | 4/4 | 60.3 | 70.0 | 49.7 |
| AdaQuant | 4/4 | 67.5 | 73.7 | 34.95 |
| Bit-Split | 4/4 | 67.56 | 73.71 | — |
| BRECQ | 4/4 | 69.60 | 75.05 | 66.57 |
| ZeroQ | 2/4 | 0.08 | 0.08 | 0.10 |
| LAPQ | 2/4 | 0.18 | 0.14 | 0.13 |
| BRECQ | 2/4 | 64.80 | 70.29 | 53.34 |

2 bit 权重加 4 bit 激活一栏值得注意：同表其它方法全部退化到随机水平（约 0.1%），BRECQ 仍保持在 53 到 70 之间。这组对照的压力测试效果比单独看 4 bit 更能说明块级重构的作用。

**与 QAT 的对照（论文的 QAT 对照表，含校准数据量与 GPU 小时）。**

| 模型 | 方法 | 位宽 | 精度 | 校准样本 | GPU 小时 |
|---|---|---|---:|---:|---:|
| ResNet-18（FP 71.08） | ZeroQ | 4/4 | 21.20 | 0 | 0.008 |
| | BRECQ | 4/4 | 69.60 | 1024 | 0.4 |
| | BRECQ（蒸馏数据） | 4/4 | 69.32 | 0 | 0.4 |
| | PACT（QAT） | 4/4 | 69.2 | 1.2M | 100 |
| | DSQ（QAT） | 4/4 | 69.56 | 1.2M | 100 |
| | LSQ（QAT） | 4/4 | 71.1 | 1.2M | 100 |
| MobileNetV2（FP 72.49） | BRECQ | 4/4 | 66.57 | 1024 | 0.8 |
| | PACT（QAT） | 4/4 | 61.40 | 1.2M | 192 |
| | DSQ（QAT） | 4/4 | 64.80 | 1.2M | 192 |
| | BRECQ | 混合/8 | 70.74 | 1024 | 3.2 |
| | HAQ（混合精度） | 混合/8 | 70.90 | 1.2M | 384 |

这组对照支持论文的核心主张：在 MobileNetV2 上，PTQ 可以超过同表的 QAT 结果，且耗时低两个数量级；用零样本的蒸馏数据也能在 4 bit 上接近完整校准集的效果。作者同时说明自己的 GPU 小时包含三档统一精度的训练，混合精度只需查表。

**检测任务。** 在 MS COCO 上，4 bit 权重加 8 bit 激活的 Faster R-CNN（ResNet-18 骨干）mAP 仅下降 0.21%；在 RetinaNet（ResNet-50 骨干）上比 ZeroQ 的混合精度方法高约 3% mAP；权重降到 2 bit 时 mAP 仍接近原始模型。检测任务只用 256 张 COCO 图像校准，且只在骨干上做块重构——论文说明 FPN 等结构没有块结构，其余部分退回逐层重构。

**首末层与数据量。** 论文的结论是保留首末层为 8 bit 并无必要：ResNet-18 全部 4 bit 的时延为 53.3 ms，反而快于「2 bit 加首末层 8 bit」的 59.8 ms，精度还高 4%。数据方面，4 bit 下增加校准样本收益很小，2 bit 下样本数增加可带来约 5% 的精度提升；用 BN 统计蒸馏出的合成数据在 4 bit 上表现不错，在 2 bit 上仍有明显差距。

## 7. 局限与适用条件

- **粒度结论来自实验。** 块级最优没有理论证明，论文自己也指出该分析不给出最优配置；换个网络族时块的定义与层间依赖都会变。
- **需要块结构。** 方法要求模型由可识别的块组成；不属于任何块的层只能退回逐层重构，检测模型里的 FPN 就是一例。
- **FIM 近似有条件。** 用梯度平方替代预激活 Hessian 成立的前提是模型分布接近数据分布，论文承认无法严格满足。
- **仍依赖校准数据与优化。** 每个块 2 万次迭代、1024 张图的成本低于 QAT，但高于纯解析方法；2 bit 下对数据量更敏感。
- **混合精度的硬件结论绑定特定实现。** 时延来自自研加速器模拟器与特定的 ARM 低位宽 GEMM 实现，不能外推到其它后端。

## 8. 与相邻方法的关系

与 [AdaRound](adaround.md) 的关系是延续加增量：舍入优化沿用，重构粒度从层变成块，预激活 Hessian 从常数对角换成 Fisher 对角。两页应合起来读——前者给出「为什么最小化权重误差不是最优」的推导，后者给出「为什么逐层重构在低位宽下不够」的推导。

与 [层输出重构与二阶误差补偿](../theory/layer-reconstruction-second-order-compensation.md) 中 GPTQ 一类解析方法相比，二者都在重构完一层/一块后继续处理下一单元，但优化对象不同：GPTQ 在连续空间直接求解其余权重的补偿量，BRECQ 在离散舍入空间上做松弛优化并学习激活步长。它们共享「局部重构是任务损失的代理」这一前提，也共享同样的边界——局部最优不等于整网最优。

在混合精度这条线上，BRECQ 提供的是卷积网络侧的一个完整实例：敏感度来自重构过程本身，搜索用遗传算法，约束是时延或体积。语言模型侧的对应做法（按层分配位宽、用代理指标排序、前缀搜索）见 [混合精度分配](../theory/mixed-precision-allocation.md)；两者的共同问题是代价模型与选择变量的定义，区别在于硬件与网络结构。
