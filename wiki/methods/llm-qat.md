# LLM-QAT：生成数据蒸馏与权重、激活、KV 联合量化

LLM-QAT 用模型生成的文本构造 QAT 数据，再让量化学生匹配浮点教师的输出概率分布。它在权重、线性层输入激活和 K/V 上放置量化节点，使训练能适应联合量化误差。“Data-Free”指不要求取得原始预训练语料；仍需生成数据、教师推理和学生训练。

本页依据 arXiv:2305.17888v1 的正文、消融与附录，回查 PDF 图 2/3、公式、主表及消融表。结论范围是原论文的 LLaMA-7B/13B/30B；没有复现训练，也没有核验真实低比特部署代码。

## 1. 问题是恢复什么能力

若直接拿一个窄领域语料继续训练量化模型，训练损失可能降低，却改变原模型在其他领域的输出与能力。作者选择让模型自己生成输入，并以浮点模型的分布作为目标，尽量保持原有行为。这里有两个独立选择：**前缀从哪里来**，以及**给这些前缀什么监督信号**。

前者决定学生见到哪些状态，后者决定在这些状态上应该学什么。两者不能用“无标签训练”一句话合并；输入分布与目标的通用区别见 [校准数据与量化范围选择](../theory/calibration-and-range-selection.md)。

## 2. 数据生成不是逐句复制教师的贪心输出

§2.1 从词表随机选取起始 token，然后自回归追加，遇到终止 token 或最大长度停止。比较三种生成方式：

1. 全程选概率最大的 token，容易重复且缺少多样性。
2. 按模型 Softmax 分布采样，增加前缀多样性。
3. 前 3–5 个 token 贪心选择，后面随机采样；作者认为初始较高置信度的 token 能确定较稳定的生成方向。

图 1 的说明提到 top-k 候选，正文则按 Softmax 分布描述，没有在本版给出可完整复原的截断参数；本文不补造 $k$、top-p 或采样温度。§3.1 明确生成器使用 LLaMA-7B、最大长度 1024；引言报告使用约 100k 条采样数据。生成器与蒸馏教师应分开记录：训练相应大小的学生时，以其预训练模型初始化并作为教师，并非所有学生都把 7B 当作蒸馏教师。

表 3 的 LLaMA-7B、W4A6 数据消融中，八项常识任务平均分为：C4 训练 61.5、全贪心生成 60.6、全采样 62.9、混合生成 63.1。WikiText-2 训练能把该任务 PPL 压到 5.5，但平均分只有 58.1，说明单域 PPL 与泛化指标可能分离。这不是生成数据总优于真实数据的证明；模型未掌握的领域也不会因采样自动得到覆盖。

## 3. 量化对象、网格和粒度

原文式 (3) 采用对称 MinMax，对每个共享统计范围 $\mathcal G$：

$$\alpha_{\mathcal G}=\frac{\max_{j\in\mathcal G}|x_j|}{2^{b-1}-1},\qquad
\hat x_i=\alpha_{\mathcal G}\operatorname{round}(x_i/\alpha_{\mathcal G}).$$

这里 $b$ 是对应对象的位宽，整数幅度覆盖 $[-(2^{b-1}-1),2^{b-1}-1]$。原式没有额外学习的裁剪阈值，尺度由极值决定；这与 [LSQ](lsq.md) 直接优化共享步长不同。全零范围等工程退化条件需要实现处理，本页不凭论文简式补成官方代码。

| 对象 | 原文规则 | 作用 |
| --- | --- | --- |
| 线性层权重 | per-channel | 图 3 的 $XW$ 记法中按输出列；若写 $W\in\mathbb R^{d_{out}\times d_{in}}$，对应按输出行共享 |
| 线性层输入激活 | per-token | 按当前 token 的特征范围量化，不把不同 token 的极值合成一个全局尺度 |
| K 与 V | 都是 per-token | 生成时当前 token 可立即量化并保存对应尺度，避免依赖未来 token |

原文图 2 覆盖注意力与 FFN 线性层的权重和输入，以及可选 K/V 节点；不支持把 Softmax、归一化、残差、embedding 和所有累加也写成同一低位宽。图示没有充分说明 RoPE 前后、KV head 内部分组或最终文件布局，需具体实现另行确认。

为什么没有用学习裁剪？作者在所测模型发现早期强裁剪会丢失重要信息，难以由微调恢复。表 4 的 LLaMA-7B、W4A8 中，权重 MinMax 配激活 LSQ 平均分 48.9，而两者 MinMax 为 64.4。这支持该设置中的选择，不能据此宣称 LSQ 对所有 LLM 无效或离群值永远不可裁剪。原文还指出对称分布结论未必适用于含 GeLU 的其他模型。

**公式阅读边界。** v1 的背景式 (2) 将归一化值 clip 到 $[0,1]$ 后直接 round；按字面会只剩两个整数水平，不能作为通用多位裁剪量化器照抄。上述主方法使用独立明确的式 (3)；背景公式的记法问题不被静默修补成作者未写出的实现。

## 4. 蒸馏优化的是概率分布

原文式 (4) 用教师概率作为软目标。为显式说明语言模型的 token 位置，将其概念展开为下式（整理者记法，不声称还原官方 loss 的具体归约）：

$$L_{KD}=-\frac1Z\sum_{i,t}m_{i,t}\sum_{c=1}^{|\mathcal V|}
p_T(c\mid x_{i,<t})\log p_S(c\mid x_{i,<t}),\qquad Z=\sum_{i,t}m_{i,t}.$$

$i$ 为序列，$t$ 为预测位置，$c$ 为词表项，$m$ 排除无效位置；教师和学生输入同一前缀。教师固定，学生量化前向产生 $p_S$。原文公式按句子写平均，未充分展开 token mask 和长度归约，因此不能把上式的按 token 平均说成已核验的代码行为。

对固定教师及前缀，交叉熵满足 $H(p_T,p_S)=H(p_T)+D_{KL}(p_T\|p_S)$。这是整理者的恒等变形：前一项不依赖学生，所以该目标是在已覆盖前缀上匹配教师分布。它不是对 logits 数值做 MSE，也没有对所有可能前缀作一致性保证。

采样得到的下一个 token 只是该分布的一次抽样，作为硬标签会丢弃其他词的相对概率。保留整个软分布能减少这种单样本监督噪声，但训练成本包含教师输出的计算与存储。量化训练还需要离散节点的代理梯度；一般原理见 [QAT 与 STE](../fundamentals/quantization/post-training-and-quantization-aware-training.md)。本版没有完整给出 round、max 及各分支的 backward 规则，不能声称它复用了 LSQ 的步长梯度。

表 5 的 W4A6 LLaMA-7B：硬标签、单独 logits、硬标签加 logits 的平均分分别为 62.4、63.1、63.2；作者采用单独 logits，但它并非每个指标都严格最佳。额外隐藏层/注意力蒸馏在该表中更差，说明额外约束未必帮助量化学生；不是中间层蒸馏普遍有害的结论。

## 5. 训练中的 K/V 与生成中的 cache

训练时，对一段序列产生的完整 K/V 张量施加逐 token 量化，再让它们进入注意力计算及反向。推理时，同样的规则用于每步新增的 K/V，连同尺度追加保存；这两个阶段共享量化语义，但不共享相同的执行调度。（§2.2.2、图 2/3。）

关键影响不止是 K/V 的局部数值误差：K 的偏差改变注意力分数，经过 Softmax 改变分配；V 的偏差改变被加权内容。整网蒸馏让模型参数在这些误差同时存在时调整。该机制解释了为什么训练阶段要包含 KV 节点，而不是只训练权重量化后再任意压缩 cache。

[KV cache 对象与粒度](../theory/kv-cache-quantization-objects-and-granularity.md) 解释在线追加与误差传播。[KIVI](kivi.md) 使用键按通道、值按 token 的训练后方案；LLM-QAT 则让模型训练适应二者逐 token 的网格。位宽、是否训练、残差窗口与评测协议不同，不能仅凭粒度名称判定哪一种更优。

## 6. 完整流程与训练成本

1. 确定 W–A–KV 各自位宽及节点，以预训练参数初始化学生并准备固定教师。
2. 使用生成器建立文本集，记录生成策略、最大长度和数量。
3. 同一输入经过教师得到软标签，经过学生的 W/A/KV 量化前向得到输出。
4. 用 logits 概率蒸馏更新学生参数，反复进行量化前向与反向；不是只做一次范围校准。
5. 评价 PPL、常识任务和 few-shot 任务，再单独验证压缩存储与执行后端。

§3.1 报告 AdamW、零 weight decay、初始学习率 $2\times10^{-5}$、余弦衰减、每 GPU batch 1；引言称在单个 8-GPU 节点完成实验。这些不足以给出一个已复原的训练 recipe：本版没有完整交代所有训练步数、梯度累积与 backward 细节，本文不补造运行命令或预算。

## 7. 质量收益与失败边界

表 1 的八项零样本常识任务均值：

| 模型 | 浮点 16–16–16 | LLM-QAT 4–8–4 | 含义 |
| --- | --- | --- | --- |
| LLaMA-7B | 66.2 | 60.7 | 相差 5.5 个百分点，不能叫作无损 |
| LLaMA-30B | 71.4 | 69.9 | 在该均值下损失较小，不代表各任务均接近 |

附录表 7 提供反例：30B 的同一 4–8–4 配置在 5-shot MMLU 为 49.3，浮点为 57.8，差距 8.5 点。小的常识均分损失不能外推为所有知识能力保持。

W4A4 更困难。表 6 中 7B 的 W4A4KV16，单独 LLM-QAT 平均分 37.6，结合 SmoothQuant 为 49.2，仍远低于浮点 66.2。W4A8KV16 加同样变换则从 64.4 降到 63.6。因此平滑与 QAT 的组合效果取决于两侧位宽，不是总有收益；也不能把 W4A8KV4 的主要结果缩写为“全 4 位”。

§5 明确本工作没有包含低比特硬件实现。附录表 8 是按上下文长度计算 KV 容量，并非实测分配器峰值显存；存储元数据、权重、临时张量与服务吞吐另算。作者对指令微调/RL 模型的泛化也列为未来工作。本文保留这些历史证据边界，不把当时的硬件支持陈述当作当前硬件现状。
