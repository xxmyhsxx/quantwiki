# Norm Tweaking：量化后仅调整归一化参数

Norm Tweaking 把小规模参数调整接在 PTQ 后面：先量化当前 Transformer 块的线性层，再冻结这些权重，只优化 LayerNorm 或 RMSNorm 的可学习参数，使块输出的逐通道均值和方差接近参考输出。它不增加低秩旁路，也不更新全部潜在权重；校准仍包含反向计算和模型生成的数据。

本页依据 `arXiv:2309.02784v2` 的正文、算法1、表1–11及必要附录，回查原始PDF方法、结果和脚注。没有核读作者实现或运行模型/GPU。前置知识见[RMSNorm统计](../implementation/rmsnorm-cuda-triton-kernels.md)、[层输出重构](../theory/layer-reconstruction-second-order-compensation.md)、[校准分布](../theory/calibration-and-range-selection.md)。

## 1. 调整什么参数，参考来自哪里

论文将当前块记为 $T(X;W_{\rm attn},W_{\rm mlp},\theta_{\rm norm})$，量化块为 $\widehat T$。优化变量只有归一化参数 $\theta_{\rm norm}$，量化后的 attention/MLP 线性权重固定。按算法1，每块依次执行：

1. 第一块接收校准输入，后续块接收**已量化并调整过的前缀**产生的输出 $qOut_{l-1}$。
2. 在量化当前块之前，用这个输入计算当前浮点块的参考输出 $fOut_l$。
3. 对当前块线性权重执行 GPTQ 等 PTQ，冻结这些权重。
4. 重算量化块输出 $qOut_l$，对两份输出的逐通道统计计算损失，反传并调整当前块归一化参数。
5. 当前量化块输出成为下一块输入。

这里的参考是“同一个量化前缀输入上的浮点当前块”，不是完整浮点教师沿自身前缀得到的全局参考轨迹。算法第12行把 $qOut_l$ 也称为“float output”；结合量化、冻结和损失时序，本页将其解释为量化块产生的浮点张量，不把该行升级为重新调用未量化权重的实现证据。

冻结线性参数只关闭其参数更新，仍需把损失对输入的梯度传回上游归一化层。默认 weight-only 路径中，固定的恢复权重可参与普通输入反传；若接激活量化插件，离散节点的具体 backward 另需实现核对。论文的方法段泛称 stochastic gradient descent，实验设置明确用 **Adam**，不能据前者声称作者采用 plain SGD。

LayerNorm 与 RMSNorm 的可学习参数和统计规则不同：RMSNorm 不减均值；LayerNorm 的仿射输出及整个残差块输出也不保证零均值。因此“恢复分布”应理解为接近参考统计，而非把所有模型强制变成零均值标准正态。

## 2. 分布损失放松了哪一种对齐

式2逐通道比较均值和方差。以 $\mu_f^c,\mu_q^c$ 为通道均值，$v_f^c,v_q^c$ 为方差，其意图可写成

$$L_{\rm dist}=\frac1C\sum_{c=1}^C\left(|\mu_f^c-\mu_q^c|+|v_f^c-v_q^c|\right).$$

$C$ 为输出通道数；若各统计是标量，原文的二范数就是绝对值，**不是平方差或MSE**。原式写 $(\sigma_f^c)^2-(\sigma_q^c)^2$，相邻文字却称 $\sigma$ 为 variance，存在记法歧义。本页按作者反复陈述的“均值和方差”解释，实际估计器、batch/token归约轴、padding mask和总体/无偏方差仍需代码核对，不能凭公式补成已核实现。

逐位置MSE要求每个对应位置接近；该损失只保留每通道的两个统计量，允许位置交换、协方差及高阶矩不同。两个位置的 $(-1,1)$ 和 $(1,-1)$ 均值0、方差1，分布损失为0，但对应位置MSE为4。机制与双通道反例见[矩匹配与逐位置重构](../theory/layer-reconstruction-second-order-compensation.md#14-逐通道矩匹配与逐位置重构约束不同的对象)。更宽松的目标可能降低对特定校准样本的逐位置拟合，但不是完整分布、语义或泛化一致性的保证。

论文给出的层级学习率为 $lr_i=lr_0(1+a\,i/L)$，$i$ 是块编号、$L$ 是块数、$a$ 是增长系数。实验从 $10^{-5}$ 开始搜索合适学习率，通常每条校准文本只遍历一次；原文未完整登记各模型的增长系数、最优学习率及微批处理。“一次”不是整个模型仅执行一次优化器更新。

## 3. 生成校准数据还包含种子分布

作者采用 LLM-QAT 的两阶段生成方式，并限制第一个随机 token 的候选语言。BLOOM 示例选英语、简体中文、法语、西班牙语、葡萄牙语，理由是词表中的语言比例与预训练语料比例不同。表1五类词表项相加为39,474，占250,680项约15.75%，与正文约写17%不一致；保留表值和文字差异。正文称相应语料超过75%，表中Corpus标成MB而正文总量为1.61TB，不能据这张表重新核算并确认该语料比例。

限制候选集合改变的是**起始token先验**，不保证生成文本的语言比例等于预训练语料，更不保证模型未知领域得到覆盖。给定种子后的自回归分布还由模型决定；混合公式及概率算例见[生成数据的种子先验](../theory/calibration-and-range-selection.md#52-生成数据仍有种子先验)。这也是生成校准与随机高斯数据的区别：相同低阶统计不意味着相同语言结构。

实验通常128条文本，最长2048 token。表8的BLOOM-7B校准消融中，无语言限制V1的WikiText2/PTB/C4 PPL为12.43/21.25/18.34，受限V2为12.32/20.95/18.28，三个指标都改善；但分别用对应真实数据校准的12.16/20.72/18.16仍更低。它支持该生成策略的局部改善，不证明所有部署分布下都优于真实语料或不再受数据选择影响。

## 5. 小参数量不等于固定低成本

BLOOM每块两个LayerNorm约有 $4h$ 参数，四个线性层约 $12h^2+9h$；这解释了优化状态小，却没有消除块前向、输入反向及参考输出成本。表3单张A100的总量化时间如下，均不是部署吞吐。

| 模型 | GPTQ / GPTQ+NT，分钟 | 额外比例 |
| --- | --- | --- |
| BLOOM-7B | 19.6 / 22.8 | 约16.3% |
| LLaMA-7B | 15.5 / 27.3 | 约76.1% |
| OPT-13B | 27.0 / 46.6 | 约72.6% |

表6的BLOOM-7B LAMBADA结果随1/2/5/10/20/50次遍历为57.4811/55.7539/52.1056/46.8465/32.3307/11.3332。这支持该设置对调整量敏感，不证明所有模型或优化协议中增加训练必然有害。表9分布损失优于所列MSE/KL的三个模型，也不能替代其他数据、目标和变量下的比较。

与[OmniQuant](omniquant.md)的可学习裁剪/等价变换、[EfficientQAT](efficientqat.md)的分阶段全参数/尺度训练及[QUASAR](quasar.md)的每步重构不同，Norm Tweaking保持当前量化主体，利用已有归一化参数改变块输出。它不新增推理模块；实际导出后的权重、激活离散反向、统计归约和端到端质量仍需实现与运行证据。
