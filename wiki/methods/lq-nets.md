# LQ-Nets：二进制基码值、交替拟合与任务训练

LQ-Nets 用少量浮点基系数和二进制标签生成可学习的标量码值，使量化器既能形成非均匀间距，又保留位平面内积的计算结构。主方案在训练前向中以当前张量的量化误差更新基系数，整网任务反传则更新浮点潜在权重；两种优化共同推进，但目标和梯度路径不同。

本页依据 LQ-Nets: Learned Quantization for Highly Accurate and Compact Deep Neural Networks，arXiv:1807.10029v1，核读固定21页PDF的正文§1–5及补充材料§1–2。正文/参考文献占文件页1–18，补充材料占19–21；归档源包的TeX仅用于合并两份PDF，公式、算法与图表编号以PDF核对。实验是作者报告，未核作者代码或运行模型、位运算内核及部署性能。

## 1. 一个标量由多个二进制基系数组合

令位宽为$k$，基向量$v\in\mathbb R^k$，一个标量的标签$e\in\mathcal E^k$。论文§3.2式5将恢复值写成

$$q=v^{\mathsf T}e.$$

这里$q$是实数码值，$e$才是可用$k$个bit保存的编码；不是把$k$个权重组合成一个向量码字。$k$个系数生成$2^k$个标签对应值，至多有$2^k$个不同数值，区别于自由学习$2^k$个独立中心的标量码本。（结构化与向量表示的区别见[码本量化](../theory/codebook-quantization-and-bit-budget.md)。）

原文脚注3规定实际使用两种标签域，正文其余推导为方便主要采用$\pm1$：

| 对象 | 标签域 | 参数化带来的性质 |
| --- | --- | --- |
| 权重 | $e\in\{-1,+1\}^k$ | 值集合关于0中心对称，通常不含精确0；特定基可生成0 |
| ReLU后激活 | $e\in\{0,1\}^k$ | 全零标签生成精确0，没有独立偏移参数 |

这些性质由式5推出，不等于作者约束所有基系数为正；0/1标签本身不保证任意学得的恢复值都非负。

**教学例。** $k=2,v=(1,3)$时，权重值为$\{-4,-2,2,4\}$，激活值为$\{0,1,3,4\}$，间距分别为2/4/2和1/2/1。它们可以非均匀，但不是任意四个数。若权重基改为$(1,1)$，四个标签只生成$\{-2,0,2\}$三个不同值，码值可碰撞。

### 编码要按恢复值排序

给定基，先枚举恢复值并排序为$c_1<\cdots<c_L$。原文以全部码值不同、$L=2^k$说明中点阈值

$$t_1=-\infty,\qquad t_l=(c_{l-1}+c_l)/2\ (2\le l\le L),\qquad t_{L+1}=+\infty.$$

按$x\in(t_l,t_{l+1}]$选择$c_l$及其二进制标签，等价于对该标量选平方误差最近码。二进制标签顺序不等于实数码值顺序，排序后须保留对应关系。中点推导的共同依据见[标量量化器](../theory/codebook-quantization-and-bit-budget.md#10.%20%E4%BB%8E%E5%A4%B1%E7%9C%9F%E7%9B%AE%E6%A0%87%E6%8E%A8%E5%AF%BC%E6%A0%87%E9%87%8F%E9%87%8F%E5%8C%96%E5%99%A8)；重复值、同距选择及实现端点规则仍未核代码。

## 2. 前向QEM与外层任务反传分工

对于当前权重或当前batch激活$x\in\mathbb R^N$，令$B=[e_1,\ldots,e_N]\in\mathcal E^{k\times N}$，论文§3.3式7的量化误差目标为

$$\min_{v,B}\ E(v,B)=\|B^{\mathsf T}v-x\|_2^2.$$

权重标签取$\pm1$，激活标签依脚注改成0/1。QEM（Quantization Error Minimization）交替执行两步：

1. 固定$v$，逐元素选最近码，更新$B$。
2. 固定$B$，将基更新视为最小二乘。式8在$B$满行秩时给出$v=(BB^{\mathsf T})^{-1}Bx$。

后一式由正规方程$BB^{\mathsf T}v=Bx$得到；若使用的码型不足，两行标签可能相关，$BB^{\mathsf T}$就不可逆。例如所有权重标签均为$(1,1)^{\mathsf T}$时秩至多1，所有激活标签为零时秩为0。原文没有披露伪逆、正则化或回退处理，不能据公式假定任意batch可直接求逆。

对固定$x$，准确选最近码、再准确解最小二乘不会增加局部$E$，但联合问题有离散变量，只给局部交替解；这不证明全局最优，也不证明整网任务损失随每次量化器拟合单调下降。量化距离与输出/任务目标的区别由[码本目标](../theory/codebook-quantization-and-bit-budget.md#2.%20%E9%80%89%E6%9C%80%E8%BF%91%E7%A0%81%E5%AD%97%E6%97%B6%EF%BC%8C%E2%80%9C%E8%B7%9D%E7%A6%BB%E2%80%9D%E6%98%AF%E4%BB%80%E4%B9%88)承接。

### 算法1的训练时序

当前基作为$v^{(0)}$；每轮用$v^{(t-1)}$选$B^{(t)}$，再用$B^{(t)}$拟合$v^{(t)}$。算法输出$B^{(T)}$，并经moving average更新保存的基；测试阶段固定基、重新编码输入，不再运行QEM。

原实验取$T=1$、moving-average factor 0.9，对激活和权重基都做平滑（§4.1）。原文没有明确EMA新旧项的具体公式，也没有明确本次输出重构采用更新前、临时还是平滑后的基；算法未写最后更新基后再重选码。本页保留这一披露粒度，实际前向配对和时序需代码核验，不能把$B^{(T)}$自动解释为更新后基的最近码。

外层训练保留浮点潜在网络权重，前向用量化值计算任务损失，反向用STE更新网络。原文对权重设输入代理处处为1；对激活，仅在当前最小/最大码值之间设为1，范围外为0，端点等号未单列。QEM主方案的基在反向中不受任务梯度更新，也不是对最小二乘求导；论文另比较直接BP学习基的方案，后续主实验选QEM。一般代理与训练变量的区别见[PTQ、QAT与代理梯度](../fundamentals/quantization/post-training-and-quantization-aware-training.md)。

## 3. 与均匀步长、偏移学习的区别

| 方法 | 码值如何生成 | 量化器怎样更新 |
| --- | --- | --- |
| LSQ v3 | 固定整数端点的均匀网格$sq$ | 任务梯度更新步长，包含内部舍入残差与专用梯度缩放 |
| LSQ+ v1 | 权重为$sq$；所选激活为$sq+\beta$ | 权重步长以统计初始化；所选激活步长/偏移以局部MSE初始化，后续按任务梯度微调 |
| LQ-Nets主方案 | $k$个系数生成$v^{\mathsf T}e$，可形成非均匀间距 | 训练前向反复QEM拟合当前张量，任务STE更新网络权重 |

因此LQ-Nets的局部拟合不只是一次初始化，也不等于LSQ的步长代理。网络在任务训练中改变权重与激活分布，基随后适应这些分布，这是主方案与任务的间接耦合。完整均匀网格训练见[LSQ](lsq.md)及[LSQ+](lsq-plus.md)。

特定基可以生成均匀间距，但表示边界仍要区分：LQ-Nets权重的$\pm1$标签生成中心对称的值集合，不能无条件称为与LSQ的$[-2^{k-1},2^{k-1}-1]$整数端点完全相同。它也不是[AQLM](aqlm.md)的多组向量码本索引；这里多个bit共同编码同一个标量。

## 4. 位平面内积要带上码域修正与基系数

令权重、激活的位宽为$k_w,k_a$，每个位平面沿$N$个输入元素组成向量$b_i^w,b_j^a$。式6通过分配律得到

$$\widehat w^{\mathsf T}\widehat a
=\sum_{i=1}^{k_w}\sum_{j=1}^{k_a}v_i^wv_j^a\langle b_i^w,b_j^a\rangle.$$

基必须在相应内积的归约范围内共享，才能移出求和。每对位平面计数后，仍需乘可学习基系数的乘积并累加；共有$k_wk_a$个逻辑位对，不表示启动相同数量的kernel，也不等于一次普通整数GEMM。

对两侧均为$\pm1$的说明性编码，物理bit以1表示$+1$，有$\langle b,c\rangle=2\operatorname{popcount}(\operatorname{XNOR}(P,C))-N$。但原实际标签是权重$\pm1$、激活0/1。令$P=(b^w+1)/2$、$A=b^a$，整理者推导为

$$\langle b^w,b^a\rangle
=2\operatorname{popcount}(P\land A)-\operatorname{popcount}(A).$$

教学反例：$b^w=(1,1),b^a=(0,0)$，真实内积0；把激活0当成$-1$直接套双符号XNOR式会得$-2$。打包尾部还须按有效位掩码计数，$N$不是补齐后的无效位数。一般固定整数位权的展开见[多位整数的二值点积](../implementation/quantized-matmul-scaling-execution.md#16.%20%E5%A4%9A%E4%BD%8D%E6%95%B4%E6%95%B0%E6%80%8E%E6%A0%B7%E7%94%A8%E4%BA%8C%E5%80%BC%E7%82%B9%E7%A7%AF%E6%89%A7%E8%A1%8C)，LQ-Nets还要保留其学习系数和标签映射。

论文只说明位运算兼容及理论潜力；没有本文低位内核或端到端推理加速实测。位平面、基、排序/编码、布局、在线打包与浮点加权的具体成本须结合后端核查，不能将“64位可一次计数”写成模型必然加速64倍。

## 5. 基与码的预算及训练条件

原方案每个卷积输出filter一套权重基、每层一套激活基（§3.2）。对$C_{out}\times D$个权重、$k_w$位编码，基以$p_v$ bit保存，理想存储为

$$N_{\rm basis}=C_{out}k_w,\qquad
S_W=C_{out}Dk_w+p_vC_{out}k_w\ \text{bit},\qquad
\overline b_W=k_w+\frac{p_vk_w}{D}.$$

基开销与主体码之比为$p_v/D$，短filter不能总视为可忽略。教学例：$D=16,k_w=2,p_v=16$时，每filter主体32 bit、基32 bit，合计4 bit/weight，而非仅2 bit。$p_v=16$只是估算假设，论文未披露完整部署基dtype；真实预算还需首末层、BN/bias、对齐和容器。每层激活基另有$k_a$个系数，激活码属于运行时数据。

训练仍保存浮点权重、梯度与优化器状态，不能按推理码率推导训练显存。求基的矩阵乘为$O(k^2N)$、求逆$O(k^3)$、右端乘法$O(kN)$；§4.4以$k\ll N$简化为$O(k^2N)$。其与卷积复杂度的比较针对普通stride-1卷积，不是depthwise或任意算子的通用开销界。

所有原实验从随机权重训练，量化器以均匀网格初始化。结构重排为BN→ReLU→Quant→Conv，首末卷积/FC层未量化（§4.1）；W/A标签不代表全网参数和训练状态都同位宽。CIFAR-10 ResNet20用batch 128、momentum 0.9、最多200 epochs、初始学习率0.1，于82/123 epochs缩小10倍、weight decay $10^{-4}$（补充§2.1）。

ImageNet较高位宽通常最多120 epochs、batch 256、weight decay $10^{-4}$、初始学习率0.1，在30/60/85/95/105 epochs缩小10倍；与HWGQ比较的1/2设置另用64 epochs及power 1的polynomial annealing，模型间学习率、batch、weight decay和增广也不同（补充§2.2）。因此跨位宽分数同时包含训练协议变化。

原激活路径针对ReLU后的CNN数据；需要保留负值的Swish/GELU/Transformer隐藏态，以及现代kernel的整数位权、尺度和布局，均需另行核对，不从这个码域证明推断无改动兼容。

## 6. 质量、迭代次数和训练成本的证据

表1在CIFAR-10 ResNet20比较基的QEM与BP优化，CIFAR-10结果为5次均值：

| 位宽W/A | BP基更新准确率 / % | QEM准确率 / % |
| --- | ---: | ---: |
| 2/32 | 90.0 | 91.8 |
| 2/2 | 88.2 | 90.2 |

这支持该实验选择QEM，不是对LSQ/PACT反向规则的单独消融。表2的2/2设置在$T=1,2,3,4$时，mean ± std为90.16±0.08、90.35±0.12、90.33±0.20、90.25±0.14%。作者未观察到增加轮数的明显稳定收益，故采用$T=1$；不表示一轮必然收敛，也不支持迭代越多任务质量越高。

表4/6的ImageNet结果相对作者各自浮点基线为：

| 模型与配置 | 作者浮点top-1 / % | 量化top-1 / % | 下降 / 百分点 |
| --- | ---: | ---: | ---: |
| ResNet18，1/2 | 70.3 | 62.6 | 7.7 |
| ResNet18，4/4 | 70.3 | 69.3 | 1.0 |
| ResNet50，4/4 | 76.4 | 75.1 | 1.3 |

极低位仍有明显损失，不能由灵活码值推出普遍无损。ResNet50用parameter-free type-A shortcut；表6部分TWN/TTQ对照为每block滤波器数1.5倍的ResNet18B。AlexNet作者浮点为61.8%、2/32为60.5%，旧参考浮点57.1%不是同一基线；不能据此称量化超过自己的浮点模型。

表7是未优化ResNet18实现的**训练耗时比例**：32/32为1.0倍，2/32为1.4倍、3/32为1.7倍、1/2为2.1倍、2/2为2.3倍、3/3为3.7倍，所有配置均未使用bitwise。它说明量化器拟合的训练成本，不能作为推理加速；原文结论仍将移动设备部署与性能测试列为后续工作。
